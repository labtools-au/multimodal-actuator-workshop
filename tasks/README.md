# Tasks

What students actually do, in the second half of the session. Unlike the bench
tests, these are written **for students**: every sketch runs the moment it is
uploaded, and the comments explain why rather than what.

Each has the same shape:

- a **CHANGE ME** block near the top, two or three numbers already set to
  something that works
- a **THINGS TO TRY** list at the bottom, four experiments from easy to hard.
  The last one usually asks for a rewrite rather than a tweak.

| # | Task | Learns |
|---|---|---|
| 01 | [`01_make_it_spin`](01_make_it_spin) | PWM, and where a motor stalls |
| 02 | [`02_make_it_tap`](02_make_it_tap) | One tap vs three. Rhythm carries meaning |
| 03 | [`03_make_it_warm`](03_make_it_warm) | Direction control, and how slow skin is |
| 04 | [`04_make_it_sense`](04_make_it_sense) | Capacitive input from a wire |
| 05 | [`05_make_it_answer`](05_make_it_answer) | Input driving output |

1 to 3 are output, 4 is input, 5 is both. Task 5's last experiment is the
closing brief, so the work carries over.

Nobody is expected to finish all five.
